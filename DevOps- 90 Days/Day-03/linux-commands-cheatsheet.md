Linux Cheat Sheet 

* **Process Management** 

ps aux → View all running processes

top → Real-time process monitoring

htop → Better interactive process view

kill <pid> → Stop process

kill -9 <pid> → Force stop

pkill <name> → Kill by process name

nproc → number of cpu cores

lscpu → cpu architecture



* **File System**

ls → List files

cd <dir> → Change directory

pwd → Show current path

mkdir <dir> → Create directory

rm -rf <dir/file> → Delete file/folder

cp <src> <dest> → Copy files

mv <src> <dest> → Move/rename

touch file → Create file

cat file → View content

tail -f file → Monitor logs live





* **Networking Troubleshooting**

ping <host> → Check connectivity

curl <url> → Test API/website

wget <url> → Download file

ip a → Show IP address

ss -tulnp → Check open ports

netstat -tulnp → Port/process mapping

nslookup <domain> → DNS lookup

dig <domain> → Detailed DNS info
